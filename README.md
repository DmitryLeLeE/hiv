# HAEMA — 3D-атлас «Кровь и вирусы»

Интерактивная scroll-история на Three.js: чёрный фон, неон, эритроциты и CD4 T-лимфоцит.
Скроллишь вниз — камера, как в документалке, показывает, как ВИЧ находит клетку и заражает её,
почему он так быстро мутирует и как его останавливает антиретровирусная терапия.

## Главы

| # | Глава | Что происходит в 3D |
|---|-------|---------------------|
| 0 | Поток | пролёт сквозь поток эритроцитов (профиль двояковогнутого диска по Эвансу–Фунгу) |
| 1 | CD4 T-клетка | живая мембрана с «топографическими» линиями и рецепторами CD4 |
| 2 | Вирион | подлёт вириона: оболочка, ~14 тримеров Env, конический капсид внутри |
| 3 | Захват CD4 | gp120 касается CD4, вспышка конформационного перехода |
| 4 | Корецептор | из мембраны поднимается CCR5 (7 трансмембранных спиралей) |
| 5 | Слияние | «гарпуны» gp41, оболочка растворяется в мембране, выброс частиц |
| 6 | Обратная транскрипция | мембрана становится прозрачной, капсид едет к ядру, за ним РНК → двойная спираль ДНК |
| 7 | Интеграция | провирус вспыхивает золотом в хроматине ядра |
| 8 | Мутации | почкуются новые вирионы — у каждого свой оттенок; в карточке мутирует геном |
| 9 | АРТ | рой препаратов пяти классов, вирионы гаснут, вирусная нагрузка падает до «< 50» |
| 10 | Н = Н | финал: неопределяемый = непередающий |

## Запуск

Сборка не нужна — Three.js подгружается с jsDelivr через import map.
Из-за ES-модулей страницу нужно открыть через любой локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Для GitHub Pages: Settings → Pages → Deploy from branch → корень репозитория.

## Файлы

- `index.html` — разметка глав и карточки с фактами
- `style.css` — HUD, стеклянные карточки, неон, мобильная вёрстка
- `main.js` — сцена: шейдеры (fresnel-свечение, шумовая мембрана), частицы, камера по сплайну, bloom + хроматическая аберрация

Масштаб условный: настоящий вирион (~100 нм) примерно в 75 раз меньше эритроцита.
Атлас — научно-популярная визуализация, не медицинская консультация.
