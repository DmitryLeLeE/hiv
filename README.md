# HAEMA — atlas sanguinis et virorum

Мрачный интерактивный атлас про ВИЧ: 3D-сцена на Three.js, которую собственный шейдер
перерисовывает **ASCII-символами из букв генома (A C G U)** или **гравюрой** — белый штрих по чёрному.
Цвета только два: кость и кровь.

## Что внутри

**Часть I — 3D-история (11 таблиц).** Скроллишь — камера, как в документалке, ведёт от потока
эритроцитов к CD4 T-лимфоциту и показывает заражение по шагам: gp120 + CD4 → корецептор CCR5 →
слияние (gp41) → капсид и обратная транскрипция → интеграция провируса → мутирующее потомство →
антиретровирусная терапия → «Н = Н».

**Часть II — приложения A–G.**
- A · Течение инфекции — интерактивный ASCII-график CD4 и вирусной нагрузки за 12 лет, без терапии и с АРТ
- B · Хроника 1981–2025
- C · Как передаётся и как нет
- D · Профилактика: презерватив, ПрЭП, ПКП (72 часа), Н = Н, стерильные иглы
- E · Тестирование и «окно» — ASCII-диаграмма периодов для ПЦР, ИФА и экспресс-тестов
- F · Цифры UNAIDS (данные за 2023 г.)
- G · Словарь, а после — список источников

## Приёмы

- **Оптика `ascii` / `гравюра`** — переключатель в шапке. Пост-процесс: плотность глифов по яркости,
  кровь определяется по «красноте» пикселя; гравюра — три слоя штриховки, точки в тенях, контуры по Собелю.
  Переход между режимами рассыпается по ячейкам.
- **Микроскоп** — под курсором линза ×400 показывает «настоящий» препарат без стилизации.
- **Выноски как в анатомическом атласе** — пунктирные линии от 3D-объектов к подписям с латынью.
- **ASCII-заголовки** рендерятся на лету из шрифта и «мутируют» буквами нуклеотидов.
- Инверсия кадра в момент слияния мембран, глитч при смене главы, «капающая» полоса прогресса,
  живые тикеры: мутирующий геном, обратная транскрипция РНК → ДНК, вирусная нагрузка.

## Запуск

Сборка не нужна, Three.js грузится с jsDelivr через import map (нужен интернет). Нужен любой локальный сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Для GitHub Pages: Settings → Pages → Deploy from branch → корень репозитория.

## Файлы

- `index.html` — таблицы, приложения, источники
- `style.css` — типографика (Cormorant Garamond, Spectral, IBM Plex Mono, Playfair Display), HUD, мобильная вёрстка
- `main.js` — сцена, шейдеры, пост-процесс ASCII/гравюры, выноски, ASCII-графики

Масштаб условный: настоящий вирион (~100 нм) примерно в 75 раз меньше эритроцита.
Научно-популярная визуализация, не медицинская консультация.
